# Playground

A test page with a station for every clicker feature: click counter, precision targets, hold timer, key counter,
chain reaction, drag and drop, level simulator (for Wait until colour, Once and Loop), scroll counter and colour
swatches. Every station stays in the same place, so recorded clicks keep landing on it.

Open `Playground.html` in a browser (no server and no internet needed):

- Windows: double-click it.
- Linux: `xdg-open tools/Playground/Playground.html`.

Then select the browser window as Click target. Click the page once before sending keys, so the browser has focus.
The images in `playground/` are Minimum Effort brand art (see THIRD_PARTY_NOTICES.md).
