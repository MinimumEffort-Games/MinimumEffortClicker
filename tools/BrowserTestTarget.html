Quick test route & what this page can measure
  1. Select this browser window in Clicker. Keep browser zoom at 100% and use a fixed window size when calibrating points.
  2. Run five slow left clicks on red, then test right/middle and a held click. Compare counts and hold durations. Use 1, 10, 20 and 100 CPS to compare receipt; the limiter is a ceiling.
  3. Focus the key pad, hold W, then try W + Shift or W + E together. Release events and OS repeat events are reported separately. Use the text box for explicit Unicode actions.
  4. Show the image and capture a tight template. Hide it, start the timer, and test image-appears/image-disappears waits. Enable duplicate match to exercise ambiguity rejection. Use the fixed solid square for red/green pixel conditions.
  5. Record clicks, keys, a drag and scrolling; edit and replay the sequence. Use the timer for waits, branches and bounded loops. Move or resize the browser to test target calibration guards.
  6. Switch away during a finite hold to test focus pause; return and confirm playback stays paused until explicitly resumed. The page clears held indicators on focus loss and logs an interruption, never a fabricated release.

This page observes browser-delivered events. It cannot prove system-wide release, physical stop latency, sleep prevention, shutdown behavior or capture permissions. Use the native TestTarget/probes for those checks. F9 remains the clicker's default Stop All. No downloads, network calls, storage or playback are triggered by this page.
