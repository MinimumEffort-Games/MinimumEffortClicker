# Minimum Effort Clicker 0.5.0-preview.34.16

First public preview: free, MIT-licensed source and a portable Windows 11 x64 app.

Download `MinimumEffortClicker-0.5.0-preview.34.16-win-x64.zip` below, extract the
complete folder and open `MinimumEffortClicker.App.exe`. The .NET runtime is included.
The automatic Source code archives are for building, not running the app.

Features include editable mouse/keyboard action lists, recording, independent
Hold/Spam toggles, local save/load, light/dark appearance, an optional status
overlay, and full/area screenshots. Playback requires an explicit start.
Default controls: F8 Actions start/stop, F9 Stop All, F10 recording start/stop.
Check Settings if you reassign keys. Use Stop All before exiting.

**Unsigned preview:** Windows may warn or block the app. No trusted publisher
signature is provided. Do not disable Windows security protections. Checksums
detect changed bytes, not publisher trust. Trusted signing is pending.

Known gaps: eight-hour full-app endurance, broader physical recording/overlap,
additional displays/DPI, suspend/session and accessibility acceptance. Some apps
ignore synthetic input or cursor-free clicks. Follow the target app's macro rules;
there is no universal compatibility or account-safety guarantee.

Keep older versions and their Data folders separate. This release uses schema 15.
Owner Data and historical unlicensed pixel assets/font are excluded. Build
provenance and per-file SHA-256 hashes are in `build-manifest.json`; the archive
checksum is attached separately. No account, installer or service is required.
