# UI art

`source/` holds the original art made for Minimum Effort Clicker: the keyboard and controller sheets
(`key-map.json` lists their icons in reading order), the mouse and keyboard pictures and the six action icons.

`generated/` is cut from it by `scripts/Build-UiArt.ps1` and built into the Windows app. Do not edit it by hand:
change a source and run the script again.
